Most files in this project end with a generated `@sourcemap` comment block: `@ctx:` says what the file does and ends with its exported names, `@dependents:` lists the files that import it.
To find the files relevant to a task, first grep case-insensitively for `@ctx:.*(word1|word2)` with words describing what the code does, or names of classes or functions (e.g. `@ctx:.*(aircraft|waypoint)`): it returns one description line per file, instead of every line of code that mentions the words. Open only the files whose description fits; grep the code itself only if that finds nothing.
After changing a file (e.g. removing a field, or changing a signature, type, return value or behavior), check how the files in its `@dependents:` use what you changed, and fix any that would break.
The blocks are maintained automatically and never reach git: never edit, move, or copy one, and never add one to a new file.
